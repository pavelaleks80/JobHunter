# Пароль приложения для почты

JobHunter работает с почтой двумя способами:

| Что делает | Переменные в `workspace/.env` | Протокол |
|---|---|---|
| **отправляет** ежедневный отчёт | `EMAIL_SENDER_LOGIN`, `EMAIL_SENDER_PASSWORD`, `SMTP_SERVER`, `SMTP_PORT` | SMTP |
| **читает** письма hh.ru и Хабр Карьеры (необязательно) | `IMAP_USER`, `IMAP_PASSWORD`, `IMAP_SERVER` | IMAP |

Обычный пароль от ящика здесь **не подойдёт**: Gmail, Mail.ru и Яндекс пускают внешние программы только по
**паролю приложения**. Это отдельный пароль, который:

- выдаётся только для почты и не открывает вход в аккаунт через браузер;
- отзывается в один клик, основной пароль при этом менять не нужно;
- показывается один раз — сразу скопируйте его в `.env`.

> ⚠️ Пароль приложения — такой же секрет, как обычный. Храните его только в `workspace/.env` (этот файл не попадает
> в git), не присылайте в чаты и issue.

## Gmail — пошагово

### Шаг 1. Включите двухэтапную аутентификацию

Без неё пункта «Пароли приложений» в аккаунте Google нет.

1. Откройте [myaccount.google.com/security](https://myaccount.google.com/security).
2. В разделе **«Вход в аккаунт Google»** (Signing in to Google) откройте **«Двухэтапная аутентификация»**
   (2-Step Verification).
3. Нажмите **«Включить»** и следуйте подсказкам: подтвердите телефон, выберите способ получения кодов
   (SMS, звонок или приложение Google на телефоне).
4. Убедитесь, что статус стал **«Включено»**.

Если двухэтапная аутентификация уже включена, переходите к шагу 2.

### Шаг 2. Создайте пароль приложения

1. Откройте [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords).
   Другой путь: [myaccount.google.com](https://myaccount.google.com) → строка поиска вверху → «Пароли приложений»
   (App passwords).
2. Google может попросить ещё раз ввести пароль от аккаунта — это нормально.
3. В поле **«Название приложения»** (App name) введите понятное имя, например `JobHunter`.
4. Нажмите **«Создать»** (Create).
5. Появится окно с паролем из **16 латинских букв**, разбитых на 4 группы: `abcd efgh ijkl mnop`.
6. **Сразу скопируйте его**: после закрытия окна посмотреть пароль ещё раз нельзя, только создать новый.

### Шаг 3. Впишите пароль в `workspace/.env`

Пробелы внутри пароля можно оставить или убрать — JobHunter их сам удалит.

**Чтение писем hh и Хабра (IMAP):**

```ini
IMAP_SERVER=imap.gmail.com
IMAP_USER=you@gmail.com
IMAP_PASSWORD=abcd efgh ijkl mnop
```

и в `workspace/config.yaml` в разделе `sources:` → `mail:` поставьте `enabled: true`:

```yaml
sources:
  mail:
    enabled: true
```

**Отправка отчёта через тот же Gmail (SMTP):**

```ini
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=465
EMAIL_SENDER_LOGIN=you@gmail.com
EMAIL_SENDER_PASSWORD=abcd efgh ijkl mnop
JOBHUNTER_RECEIVER=you@gmail.com
```

Один и тот же пароль приложения подходит и для чтения, и для отправки. Можно создать два разных, например
`JobHunter IMAP` и `JobHunter SMTP`, — тогда каждый отзывается отдельно.

### Шаг 4. Проверьте

```bash
jobhunter check
```

Ожидаемые строки (пароль не выводится):

```
[OK] почта IMAP imap.gmail.com: вход OK, папка INBOX (INBOX)
[OK] SMTP: логин и пароль заданы (пароль не показывается)
```

Отправку проверит первый `jobhunter run`: письмо придёт на `JOBHUNTER_RECEIVER`, а его копия сохранится в
`workspace/logs/last_email.html`.

### Если что-то не так

| Сообщение или ситуация | Причина и что делать |
|---|---|
| На странице «Пароли приложений»: *The setting you are looking for is not available for your account* | Не включена двухэтапная аутентификация (шаг 1). Ещё варианты: включена «Расширенная защита» (Advanced Protection) или это рабочий/учебный аккаунт, где пароли приложений запретил администратор — используйте личный Gmail. |
| `Application-specific password required` | В `.env` указан обычный пароль от аккаунта, а не пароль приложения. |
| `Invalid credentials` / `Username and Password not accepted` | Опечатка, пароль отозван, или `IMAP_USER`/`EMAIL_SENDER_LOGIN` не совпадает с аккаунтом, в котором создан пароль. Создайте новый пароль приложения. |
| Пароль перестал работать после смены основного пароля | Google отзывает все пароли приложений при смене пароля аккаунта — создайте новый. |
| IMAP не подключается | Проверьте Gmail → ⚙ Настройки → «Все настройки» → «Пересылка и POP/IMAP»: если там есть переключатель «Доступ по протоколу IMAP», он должен быть включён (в новых аккаунтах IMAP включён всегда и переключателя нет). |
| Письма hh/Хабра фильтрами уходят из «Входящих» | В `config.yaml` укажите `sources.mail.folder: ALL` — JobHunter будет искать во «Всей почте». |

### Как отозвать пароль

[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → значок корзины рядом с `JobHunter`.
JobHunter сразу перестанет иметь доступ к почте.

## Mail.ru

1. [id.mail.ru](https://id.mail.ru) → **«Безопасность»** → **«Пароли для внешних приложений»**.
   Если пункта нет — сначала включите двухфакторную аутентификацию там же.
2. **«Добавить»** → название `JobHunter` → доступ **«Полный доступ к Почте»** (IMAP и SMTP).
3. Скопируйте пароль.

```ini
SMTP_SERVER=smtp.mail.ru
SMTP_PORT=465
EMAIL_SENDER_LOGIN=you@mail.ru
EMAIL_SENDER_PASSWORD=пароль_приложения

IMAP_SERVER=imap.mail.ru
IMAP_USER=you@mail.ru
IMAP_PASSWORD=пароль_приложения
```

## Яндекс Почта

1. [id.yandex.ru](https://id.yandex.ru) → **«Безопасность»** → **«Пароли приложений»** → **«Почта»**.
2. Введите название `JobHunter` → **«Создать»** → скопируйте пароль.
3. В Яндекс Почте: ⚙ → **«Все настройки»** → **«Почтовые программы»** → включите
   «С сервера imap.yandex.ru по протоколу IMAP» и способ авторизации «Пароли приложений и OAuth-токены».

```ini
SMTP_SERVER=smtp.yandex.ru
SMTP_PORT=465
EMAIL_SENDER_LOGIN=you@yandex.ru
EMAIL_SENDER_PASSWORD=пароль_приложения

IMAP_SERVER=imap.yandex.ru
IMAP_USER=you@yandex.ru
IMAP_PASSWORD=пароль_приложения
```

## Какую почту для чего использовать

- **Читать** нужно тот ящик, куда приходят письма hh.ru и Хабр Карьеры, — обычно ваш основной.
- **Отправлять** можно с того же ящика самому себе. Удобный вариант — отдельный ящик-«бот» (например, на Mail.ru):
  письма отчёта приходят от другого отправителя, их легко отфильтровать, а основной ящик используется только
  на чтение.
