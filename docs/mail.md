# Почта: подборки hh и отклики

Площадки сами присылают на почту почти всё, что нужно для воронки. JobHunter читает эти письма и сам
обновляет статусы — руками вести статистику не нужно.

## Что распознаётся

| Отправитель | Письмо | Что делает JobHunter |
|---|---|---|
| hh.ru | «Вакансии по подписке: …» | вакансии из подборки → в отчёт (сверка только по названию) |
| hh.ru | «Работодатель не готов пригласить вас…» | статус **Отказ** |
| hh.ru | «Вам написали по вакансии…», «Сообщение от работодателя» | статус **Ответили** |
| Хабр Карьера | «Вы откликнулись на вакансию …» | статус **Откликнулся** (ссылка и компания из письма) |

getmatch об откликах писем не присылает — такие отклики отмечайте в колонке «Статус» Excel-отчёта или командой
`jobhunter applied <ссылка>`.

Статусы только растут: Откликнулся → Ответили → Приглашение → Оффер. «Отказ» и «Не интересно» ставятся всегда.

## Как подключить (Gmail)

1. Включите двухэтапную аутентификацию: myaccount.google.com → Безопасность.
2. Создайте пароль приложения: myaccount.google.com → Безопасность → **Пароли приложений** → 16 символов.
3. Включите IMAP: Gmail → Настройки → Пересылка и POP/IMAP.
4. В `workspace/.env`:
   ```
   IMAP_SERVER=imap.gmail.com
   IMAP_USER=you@gmail.com
   IMAP_PASSWORD=abcd efgh ijkl mnop
   ```
5. В `workspace/config.yaml`: `sources.mail.enabled: true`.
6. На hh.ru настройте подписку на вакансии (автопоиск) с отправкой на эту почту.
7. `jobhunter check` — строка «почта IMAP: вход OK».

Если письма площадок фильтрами уходят из «Входящих» в другие папки, укажите `sources.mail.folder: ALL` —
JobHunter сам найдёт папку «Вся почта» (её имя на IMAP зависит от языка интерфейса Gmail).

Mail.ru и Яндекс работают так же: `imap.mail.ru` / `imap.yandex.ru` и пароль для внешних приложений.

## Безопасность

- Ящик открывается **только на чтение** (`EXAMINE`), письма читаются через `BODY.PEEK` — не помечаются прочитанными,
  ничего не удаляется и не перемещается.
- Читаются только письма от `noreply@hh.ru` и `career.habr.com` за последние `sources.mail.days` дней.
- Ссылки hh в письмах персональные (содержат ключ входа в аккаунт): сохраняется только `https://hh.ru/vacancy/<id>`.
- Тексты писем никуда не сохраняются.

## Письмо не распознаётся?

Площадки иногда меняют вёрстку. Откройте [issue](https://github.com/pavelaleks80/JobHunter/issues/new?template=mail_sample.yml)
и приложите **обезличенный** текст письма (имя, ссылки с ключами, телефоны — уберите).
