# Сопроводительные письма, дубли и зарплаты

## Сопроводительные письма

```bash
jobhunter cover https://career.habr.com/vacancies/1000000001
jobhunter cover --fit 5          # для 5 лучших вакансий «Подходит/Частично» без отклика и без письма
jobhunter cover <url> --force    # переписать готовый черновик
```

Что получает модель: текст резюме, краткий профиль, требования вакансии и результат сверки — что закрыто, а что нет.
Правила для неё:

- **только факты из резюме** — никаких выдуманных проектов и цифр;
- 2–3 главных требования вакансии подкрепить конкретикой из опыта;
- пробел упоминается честно и одной фразой, только если есть смежный опыт;
- без штампов вроде «ответственный, коммуникабельный» и без плейсхолдеров [Имя].

Черновик сохраняется в `workspace/covers/<площадка>_<id>.md` с шапкой: вакансия, ссылка, вердикт сверки.
В Excel-отчёте колонка **«Письмо»** ведёт на файл, в письме-отчёте у вакансии появляется «✉ письмо готово».

**Перечитайте черновик перед отправкой** — это заготовка, а не готовый текст.

Настройки — секция `cover` в `config.yaml`:

```yaml
cover:
  words: 170
  tone: "деловой, живой, без канцелярита и штампов"
  signature: "Анна Смирнова, @anna_pm"
  extra: "упомяни, что готова к гибридному формату"
```

Для вакансий hh из почты описания нет, поэтому письмо пишется по названию и резюме — получится более общим.

## Склейка дублей

Одна и та же вакансия часто висит на getmatch, Хабре и hh. JobHunter считает вакансии дублями, если:

- одна и та же компания — одно название начинается с другого: «МТС Банк» и «МТС Банк. Головной офис»;
- названия почти совпадают (≥ 88% после удаления города и формата работы);
- вакансии с **разных** площадок.

В отчёте остаётся одна строка — копия с описанием (getmatch → Хабр → hh). В колонке «Также на» — остальные
площадки со ссылкой. Отклик или отказ на любой копии относится ко всей вакансии. Вакансия считается новой, только если
ни одну её копию раньше не видели.

## Зарплаты

```bash
jobhunter salaries              # за 90 дней
jobhunter salaries --days 30
```

Считается **верх вилки на руки**: вилки «до вычета» пересчитываются по `salary.tax`, вакансии без вилки не учитываются,
дубли — тоже. Что вы увидите:

- по каждой роли из `scoring.roles` — 25-й перцентиль, медиану, 75-й перцентиль;
- медиану по неделям — растёт рынок или проседает;
- долю вакансий, где вилка вообще указана;
- долю вилок не ниже вашей цели `salary.target` — реалистична ли цель.

То же — на листе «Зарплаты» Excel-отчёта и в блоке «Зарплаты» письма. Статистика копится в базе с каждым запуском:
через пару недель ежедневной работы цифрам уже можно доверять.

## Чёрный список компаний

```yaml
scoring:
  blacklist_companies: ["ромашка", "рога и копыта"]
```

Подстроки названий компаний (без учёта регистра). Такие вакансии в отчёт и письмо не попадают.
