# Изменения

## 0.4.0 — 2026-10-09

- **Широкий поиск** (`scoring.wide`, включён по умолчанию): вакансия, чьё название не совпало ни с одной ролью,
  больше не отбрасывается — её описание сверяется с резюме, и при вердикте не хуже `wide_min` (по умолчанию
  «Подходит») она попадает в отчёт с пометкой «нестандартное название» и баллом роли `wide_points`. Критичный пробел
  прямо в названии (ML, Golang, 1С…) отсеивает её до загрузки описания; стоп-слова `exclude` и подборки hh — как раньше.
  На живых данных: из 16 таких вакансий getmatch 5 подошли («Начальник отдела CRM», «Руководитель отдела развития
  и эффективности», «Старший менеджер по развитию облачных продуктов»…).

## 0.3.1 — 2026-10-09

- **Шаблон трекера откликов:** `jobhunter init` создаёт в `workspace` пустую таблицу «Мои отклики.xlsx» (Вакансия,
  Ссылка, Компания, Дата отклика, Ответили, Собеседование, Итог со списком Отказ/Снята/Оффер, Заметки) и лист
  «Как заполнять». Колонки по умолчанию в `tracker_import` совпадают с шаблоном — для чтения достаточно
  `enabled: true`. Относительный путь трекера считается от папки `workspace`.

## 0.3.0 — 2026-10-09

- **Свой трекер откликов:** JobHunter читает вашу Excel-таблицу откликов (секция `tracker_import`, буквы колонок,
  несколько колонок через запятую) при каждом запуске и командой `jobhunter import-tracker` — уже откликнутые
  вакансии больше не приходят в письме. Только чтение; файл может быть открыт в Excel (читается сохранённое).
  Статусы: ответ, приглашение, отказ, «снята», оффер — по колонкам и регуляркам; повтор ничего не дублирует;
  отклики без даты ответа не искажают медиану.
- `jobhunter check` проверяет чтение трекера; подсказка про VPN — только для Хабра.

## 0.2.2 — 2026-10-09

- Документация: как читать записи вида `sources.mail.enabled` и находить их в `config.yaml` (вложенность
  отступами), пример включения почты прямо в YAML — [docs/setup.md](docs/setup.md).
- Сверка: слово «ценообразование» больше не считается требованием к образованию; распознаётся больше
  формулировок личных качеств.

## 0.2.1 — 2026-10-08

## 0.2.0 — 2026-10-08

- **Сопроводительные письма:** `jobhunter cover <ссылка>` или `jobhunter cover --fit 5` — черновик под вакансию из
  резюме, профиля и требований (только факты из резюме, без штампов) в `workspace/covers/`; в Excel — колонка «Письмо»
  со ссылкой на черновик, в письме — «✉ письмо готово». Настройки — секция `cover` в `config.yaml`.
- **Склейка дублей:** одна вакансия с getmatch, Хабра и hh показывается один раз (основная — с описанием),
  в отчёте — «Также на»; отклик на любую копию засчитывается всей вакансии.
- **Аналитика зарплат:** лист «Зарплаты» (по ролям: 25% / медиана / 75%, по неделям), блок в письме, команда
  `jobhunter salaries`; доля вакансий с вилкой и доля вилок не ниже вашей цели.
- **Чёрный список компаний:** `scoring.blacklist_companies`.
- База из 0.1.0 обновляется автоматически.

## 0.1.0 — 2026-10-08

Первый публичный выпуск. В основе — личный инструмент автора, которым он пользовался в поиске работы.

- Источники: getmatch, Хабр Карьера, подборки hh.ru из почты.
- Профиль кандидата из резюме (PDF, DOCX, TXT) через любую LLM с OpenAI-совместимым API; заготовка без LLM.
- Сверка требований вакансии с профилем: правила с пояснениями, процент соответствия, вердикт, стоп-факторы;
  необязательный ИИ-судья для нераспознанных требований с кэшем.
- Воронка откликов в SQLite: события из писем (отклики Хабра, отказы и ответы работодателей hh), колонка «Статус»
  в Excel, команда `jobhunter applied`; `tracker.xlsx` и статистика.
- Excel-отчёт («К отклику», «Все», «Пробелы резюме», «Воронка», «Источники») и HTML-письмо со всеми подходящими
  вакансиями без отклика, новые — 🆕.
- CLI: `init`, `profile`, `run`, `applied`, `stats`, `check`; Docker; запуск по расписанию.
