# Изменения

## 0.2.0 — 2026-10-08

- **Сопроводительные письма:** `jobhunter cover <ссылка>` или `jobhunter cover --fit 5` — черновик под вакансию из
  резюме, профиля и требований (только факты из резюме, без штампов) в `workspace/covers/`; в Excel — колонка «Письмо»
  со ссылкой на черновик, в письме — «✉ письмо готово». Настройки — секция `cover` в `config.yaml`.
- **Склейка дублей:** одна вакансия с getmatch, Хабра и hh показывается один раз (основная — с описанием),
  в отчёте — «Также на»; отклик на любую копию засчитывается всей вакансии.
- **Аналитика зарплат:** лист «Зарплаты» (по ролям: 25% / медиана / 75%, по неделям), блок в письме, команда
  `jobhunter salaries`; доля вакансий с вилкой и доля вилок не ниже вашей цели.
- **Чёрный список компаний:** `scoring.blacklist_companies`.
- База из 0.1.0 обновляется автоматически.

## 0.1.0 — 2026-10-08

Первый публичный выпуск. В основе — личный инструмент автора, которым он пользовался в поиске работы.

- Источники: getmatch, Хабр Карьера, подборки hh.ru из почты.
- Профиль кандидата из резюме (PDF, DOCX, TXT) через любую LLM с OpenAI-совместимым API; заготовка без LLM.
- Сверка требований вакансии с профилем: правила с пояснениями, процент соответствия, вердикт, стоп-факторы;
  необязательный ИИ-судья для нераспознанных требований с кэшем.
- Воронка откликов в SQLite: события из писем (отклики Хабра, отказы и ответы работодателей hh), колонка «Статус»
  в Excel, команда `jobhunter applied`; `tracker.xlsx` и статистика.
- Excel-отчёт («К отклику», «Все», «Пробелы резюме», «Воронка», «Источники») и HTML-письмо со всеми подходящими
  вакансиями без отклика, новые — 🆕.
- CLI: `init`, `profile`, `run`, `applied`, `stats`, `check`; Docker; запуск по расписанию.
