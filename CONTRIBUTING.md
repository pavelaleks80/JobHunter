# Как помочь проекту

Спасибо, что заглянули! Любая помощь полезна: баг-репорт, образец письма, правка документации, код.

## Сообщить об ошибке

Откройте [issue](https://github.com/pavelaleks80/JobHunter/issues/new/choose) по шаблону. Приложите вывод
`jobhunter check` и фрагмент `workspace/logs/jobhunter.log`. **Не прикладывайте** `.env`, `profile.yaml`,
резюме, базу и отчёты — в них личные данные.

## Письмо площадки не распознаётся

Это самый ценный вклад: площадки меняют вёрстку, и без образцов парсер не починить. Шаблон
«Образец письма» — приложите текст письма, **удалив** имя, телефоны, адреса и ссылки с параметрами
(`loginkey`, `signature`, `token`).

## Код

```bash
git clone https://github.com/pavelaleks80/JobHunter.git
cd JobHunter
pip install -e ".[dev]"
pytest -q
ruff check jobhunter tests
```

- Тесты не ходят в сеть: сайты и LLM подменяются заглушками, письма — обезличенными образцами в `tests/`.
- Новый источник вакансий — модуль в `jobhunter/sources/` с функциями `fetch(s, settings)` и `detail(s, settings, id)`,
  возвращающими вакансии в формате `sources.vacancy()`.
- Новый тип письма — строка в `KINDS` и парсер в `jobhunter/tracker/mail_events.py` + тест в `tests/test_mail.py`.
- Код и комментарии — на русском, стиль — `ruff` (строки до ~120 символов).

## Чего проект не делает

Автоотклики, обход капч и защит, парсинг hh.ru, хранение чужих паролей на сервере. Такие PR не принимаются.
