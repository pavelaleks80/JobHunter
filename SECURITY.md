# Безопасность

JobHunter работает с чувствительными данными: резюме, пароли приложений к почте, ключ LLM.

## Как устроено

- Секреты хранятся только в `workspace/.env` (в `.gitignore`) и не выводятся в логи, отчёты и `jobhunter check`.
- Почта открывается только на чтение; персональные ключи входа из ссылок hh не сохраняются.
- Наружу уходят: текст резюме — выбранной вами LLM (один раз, `jobhunter profile`); в режиме `hybrid` — тексты
  требований вакансий и краткий профиль.

## Рекомендации

- Используйте **пароли приложений**, а не основной пароль от почты, — их можно отозвать в любой момент.
- Не публикуйте содержимое `workspace/` — ни в issue, ни в форках.

## Сообщить об уязвимости

Не открывайте публичный issue — воспользуйтесь
[Report a vulnerability](https://github.com/pavelaleks80/JobHunter/security/advisories/new) на вкладке Security.
